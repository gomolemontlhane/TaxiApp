# TaxiApp

A minimalist navigation web app for South African minibus taxis.

## Project

TaxiApp helps users discover:

- Nearby taxi ranks
- Nearby taxi stops
- Taxi routes
- Transfer points
- Estimated journey times
- Live taxi locations

## Tech Stack

- React
- Vite
- Tailwind CSS
- Zustand
- Node.js
- Express
- MongoDB
- Socket.IO
